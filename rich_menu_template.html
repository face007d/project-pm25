🎨 วิธีใช้งาน Rich Menu Template

  1. บันทึกเป็นรูปภาพ:
    • Windows: กด Win + Shift + S แล้วเลือกพื้นที่สี่เหลี่ยมด้านบน
    • หรือคลิกปุ่ม "บันทึกเป็นรูปภาพ" ด้านล่าง
  2. ขนาดรูปภาพ: ต้องเป็น 2500 x 843 pixels (อัตราส่วนที่ LINE กำหนด)
  3. อัพโหลดไปที่ LINE:
    • เข้า LINE Developers Console
    • เลือก Messaging API Channel ของคุณ
    • ไปที่ Rich Menu → Create
    • อัพโหลดรูปภาพนี้
  4. หรือใช้ API: เรียก POST /api/create-rich-menu แล้วอัพโหลดรูปผ่าน LINE API
